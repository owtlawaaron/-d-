# 03. FPS戦闘仕様（1v1 攻防戦）

## 3.1 ルール概要

| 項目 | 値 |
| --- | --- |
| 形式 | 1 vs 1（攻め1人 / 守り1人） |
| 制限時間 | **90秒** |
| 攻め側の勝利条件 | 守り側の **座席権クリスタル** を破壊 |
| 守り側の勝利条件 | 90秒経過 / 攻め側のリスポーン残数を全て枯らす |
| 準備フェーズ | 15秒（守り側のみ設置物を配置。攻め側は武器選択とマップ確認） |

**設計意図**: 守り側が「席を持っている既得権益者」なので、有利側に置く。
攻め側は「時間内に押し切る」というプレッシャーを負う。挑戦のコストを表現する。

## 3.2 タイムライン

```
T-5.0s 〜 T+0.0s : アリーナ生成演出（docs/05）— 操作不可
T+0.0s 〜 T+15.0s: 準備フェーズ
                     守り: バリケード配置（机3 / 教科書シールド2 / 画鋲トラップ2）
                     攻め: 武器2種の選択・スポーン地点の選択（後方3箇所）
T+15.0s          : "CLASS START!" 戦闘開始（タイマー90秒スタート）
T+15.0s 〜 T+105s: 戦闘
  ├ 残り30秒: クリスタルのシールドが剥がれ被ダメ +30%（攻め側救済＝オーバータイム防止）
  └ 残り10秒: 全体が赤くなる・チャイム音が鳴る
T+105s           : 時間切れ → 守り勝ち
```

## 3.3 リスポーン

| | 攻め側 | 守り側 |
| --- | --- | --- |
| リスポーン回数 | **3回** | **1回** |
| 復帰待ち時間 | 5秒 | 12秒 |
| 復帰位置 | 教室後方の3地点からランダム | 自席（クリスタル横） |
| 全消費後の死亡 | **即敗北**（守り勝ち） | **復帰しない**。クリスタルは無防備になるが試合は継続 |

守り側は復帰が遅いが、その間クリスタルが自動シールド（被ダメ -50%）を張る。
→ 「守りをキルしてから殴る」だけでは押し切れず、**継続的な圧力**が必要になる。

## 3.4 座席権クリスタル

- 位置: 守り側の席（机）の上、高さ 1.4m に浮遊。半径 0.35m の八面体。
- HP: **1000**
- 被ダメージ倍率: 銃撃 = 武器ダメージの **0.6倍** / 近接 = **2.5倍**
- 近接で殴るには相手の目の前に飛び込む必要がある → リスクとリターンの設計
- 破壊されると教室ごとガラスのように砕けて演出終了

**平均破壊時間の試算**（チョークSMG: 8dmg × 10発/秒 = 80dps → 対クリスタル48dps）
→ 無抵抗なら約21秒。実際は守りの妨害で射線が通る時間が限られるため、
`tools/balance_sim.py` の実測で **平均決着 73.5秒 / 時間切れ 27.5%** に収まる。

### 検証済みバランス（4万試合）

| 指標 | 実測 | 目標 |
| --- | --- | --- |
| 互角の攻め側勝率 | **43.7%** | 42〜46% |
| 能力差 +3 の攻め側勝率 | **63.7%** | 60〜68% |
| 平均決着時間 | **73.5秒** | 55〜75秒 |
| 時間切れ（守り勝ち）の割合 | **27.5%** | 25〜35% |

→ 守りがやや有利、かつ実力差が効くが確定ではない、という設計通りの分布。
数値を触ったら `python3 tools/balance_sim.py` で再検証すること。

## 3.5 プレイヤー移動

| 項目 | 値 |
| --- | --- |
| 歩行 | 3.0 m/s |
| 走行 | `moveSpeed`（4.5〜5.6 m/s） |
| しゃがみ | 1.8 m/s（机の下に隠れられる） |
| ジャンプ | 初速 4.6 m/s（高さ約1.08m） |
| 重力 | -18.0 m/s²（ゲーム的に重め） |
| 自動ステップ | 0.45m（椅子に自動で乗れる） |
| 机に乗る | ジャンプ + 自動ステップで可（机高 0.72m） |
| スライディング | 走行中しゃがみ。1.1秒間 6.5→2.0 m/s に減速。机の下を潜れる |
| 空中制御 | 地上加速度の 30% |
| コヨーテタイム | 0.12秒 |

視点: FOV 75°（ADS時 55°）、マウス感度は 0.0015 rad/px を基準に設定可。

## 3.7 NPC AI（3D戦闘用）

### 難易度パラメータ（能力値から算出）

```
aimError    = (9 - nerve) * 0.9      [degree]  // 0.9° 〜 7.2°
reactionMs  = 420 - academics * 22   [ms]      // 200ms 〜 398ms
burstLength = 3 + floor(nerve / 3)             // 3 〜 6 発
peekBravery = nerve / 10                       // 0.1 〜 1.0
```

### ステートマシン（攻め側）

```
SEARCH ──見つけた──▶ ENGAGE ──HP<35%──▶ RETREAT ──回復/5秒──▶ SEARCH
   │                    │                                       ▲
   │                    └──残り25秒 & 視界クリア──▶ RUSH_CRYSTAL ─┘
   └──残り15秒──▶ RUSH_CRYSTAL（自殺覚悟の突撃）
```

### ステートマシン（守り側）

```
HOLD_ANGLE ──足音/被弾──▶ ROTATE ──接敵──▶ TRADE ──HP<30%──▶ FALLBACK
     ▲                                                          │
     └──クリスタルHP<50% ──▶ LAST_STAND（クリスタル密着で射線を切る）◀┘
```

### 経路探索

教室は狭いので **ナビメッシュ不要**。手打ちの **ウェイポイントグラフ**（20〜28ノード）＋
`Raycaster` による直線視認チェック（見えていれば直進、見えなければ最短経路）で十分。
ウェイポイントは `data/arenas/*.json` の `waypoints` に定義する。

## 3.8 アリーナ（拡張教室）

バトル中の教室は **2倍スケール** に拡張される（生徒がミニチュア化した感覚）。

| 要素 | 実寸 | バトル時 |
| --- | --- | --- |
| 教室 | 9m × 8m × 3m | **18m × 16m × 6m** |
| 机 | 0.65 × 0.45 × 0.72m | 1.3 × 1.05 × 0.9m（胸高カバー。乗って高所を取れる） |
| 黒板側 | — | 攻め側スポーン地点は逆側（教室後方） |

- **攻め側スポーン**: 教室後方の3地点（守り側の席が後方なら前方に反転する）
- **カバー**: 机30台（InstancedMesh）、教卓、ロッカー、掃除用具入れ、カーテン（貫通可）
- **高所**: ロッカーの上（+2.4m）へ机経由で登れる。強ポジだが遮蔽なし
- **貫通**: カーテン・教科書シールドは弾が貫通（ダメージ 50%）。机・壁は不貫通

> 守り側の席の位置によってアリーナのカバー配置が変わる。
> 「窓際最後列は防衛しやすいが、逃げ場がない」など席ごとの個性が出る。
