## リスクと対策

| リスク | 対策 |
| --- | --- |
| 3Dモデル制作で止まる | P0 の「箱人間」で最後まで作り切る。モデルは M6 |
| 自前物理でキャラが壁を抜ける | 軸分離＋移動量を 0.2m 以下に分割してスイープ。M1 でテストシーンを作る |
| NPC が強すぎ/弱すぎ | `aimError` と `reactionMs` を JSON 化し、Python で自動調整 |
| メタゲームが単調 | 遺恨・素行点・連鎖挑戦で毎ターンの状況を変える（docs/02） |
| 演出が重い | アリーナ構築を演出の前に完了させ、演出は uniform 操作のみにする |
