# 01. ゲーム全体設計

## 1.1 コンセプト

**「席替えの不平不満を、実力行使で解決する」**

現実の席替えでは、後ろの席・窓際を引いた人間に対して不満を溜め込むしかない。
このゲームでは、その不満をトリガーに **1対1のFPSデュエル** が発生し、
勝てば相手の席を物理的に奪える。

- ジャンル: 席替えシミュレーター × アリーナFPS（1v1・攻防分離型）
- 視点: 一人称（バトル中）／ 見下ろし俯瞰（教室・席替えフェーズ）
- 1プレイの長さ: 1学期 = 10ターン ≒ 20〜30分
- プラットフォーム: ブラウザ（PC / キーボード＋マウス）

## 1.2 プレイヤーの立ち位置

プレイヤーは **クラス30人のうちの1人**。NPCと同じルールで席替えに参加する。

| 状況 | プレイヤーの操作 |
| --- | --- |
| 自分が挑戦する | 攻め側としてFPS操作 |
| 自分が挑戦される | 守り側としてFPS操作（＋配置フェーズ） |
| NPC同士の対戦 | 観戦する / スキップ（内部シミュレーションで即決着） |

NPC同士の戦闘は毎回3Dで再生すると冗長なので、**抽象戦闘シミュレータ**（勝率計算）で
即座に解決し、結果だけ教室に反映する。プレイヤーが「観戦」を選んだ時だけ3D再生する。

## 1.3 ゲームサイクル（1ターン＝学校の1日）

```
朝: 席替えフェーズ
  ├ ターン1 のみ: 全席ランダム抽選（クラス替え）
  └ ターン2以降: 前ターンの結果を引き継ぎ

昼: 不満フェーズ
  ├ 全生徒の「不満度」を再計算
  ├ 閾値を超えた生徒が挑戦キューに入る（1ターンあたり最大3件）
  └ プレイヤーは自分の挑戦を「する / しない」選択できる（挑戦トークン 1/ターン）

放課後: 決闘フェーズ
  ├ 挑戦キューを順に処理
  ├ プレイヤー関与 → 5秒のアリーナ生成 → 90秒のFPS戦
  └ NPC同士 → 抽象シミュレーション

夜: 結果フェーズ
  ├ 席の交換を反映
  ├ 素行点 / 人望 / 遺恨(grudge) の更新
  └ 次ターンへ
```

## 1.4 勝利条件（メタゲーム）

学期末（10ターン終了時）に、**プレイヤーの席の価値（perceivedValue）** でランク評価。

| 評価 | 条件 |
| --- | --- |
| S: 玉座 | 最終席価値 90 以上 かつ 無敗 |
| A: 王 | 最終席価値 85 以上 |
| B: 勝ち組 | 最終席価値 70 以上 |
| C: 平穏 | 50〜69 |
| D: 敗残 | 50 未満 |
| F: 学級崩壊 | 素行点が 0 になり学級指導（強制終了） |

**素行点（Conduct）**: 初期100。挑戦するたび -5、負けると追加 -10、勝つと -2（暴力は暴力）。
0 になるとゲームオーバー。「勝ちまくれば良い」ではなく、**挑戦回数を選ぶ**駆け引きになる。

## 1.5 生徒（Student）のステータス

素の能力値は 1〜10。これがバトル性能とメタ性能の両方に効く。

| ステータス | バトルへの影響 | メタへの影響 |
| --- | --- | --- |
| `athletics` 運動 | 移動速度・ジャンプ・スライディング距離 | — |
| `nerve` 度胸 | 被弾時のブレ低減・リコイル制御 | 挑戦の踏み切りやすさ |
| `academics` 学力 | 武器リロード速度・弾の軌道補正 | 席の期待値（自己評価）が上がる |
| `charisma` 人望 | — | 応援バフ（観客の声援でHP+10%）、遺恨の受けにくさ |
| `stamina` 体力 | 最大HP（100 + stamina×5） | — |

### 派生パラメータ

```
maxHP        = 100 + stamina * 5             // 105 〜 150
moveSpeed    = 4.4 + athletics * 0.12  [m/s] // 4.52 〜 5.6
reloadScale  = 1.20 - academics * 0.02       // 1.18x 〜 1.00x（小さいほど速い）
recoilScale  = 1.15 - nerve * 0.015          // 1.135 〜 1.00
expectedSeat = 40 + (academics + athletics + charisma) * 2   // 自己評価（席の期待値）
```

`expectedSeat` が「自分はこの程度の席に座って当然」という値。
実際の席価値がこれを下回ると不満が溜まる（→ docs/02）。

## 1.6 パーソナリティ（挑戦AIの性格）

| type | 説明 | 挑戦閾値 | ターゲット選好 |
| --- | --- | --- | --- |
| `hothead` 短気 | すぐキレる | 40 | 価値差が最大の相手 |
| `calculator` 計算型 | 勝てる相手だけ狙う | 65 | 期待値（勝率×価値差）が最大 |
| `loyal` 義理堅い | 友達の席は狙わない | 60 | 友好度が低い相手のみ |
| `pacifist` 事なかれ | ほぼ挑戦しない | 90 | — |
| `tyrant` 覇者 | 常に最高の席を狙う | 30 | 席価値トップの相手固定 |
| `avenger` 復讐者 | 遺恨を優先 | 55 | grudge が最大の相手 |

## 1.7 遺恨（Grudge）システム

負けた側は勝った側に `grudge += 25`（上限100）を蓄積する。
grudge は不満度に加算されるので、**リターンマッチが自然発生する**。
勝つと grudge は 0 にリセット。3ターン経過ごとに -10 で自然減衰。

## 1.8 世界観・トーン

- **舞台**: ごく普通の日本の公立中学校の教室。ただしバトル中だけ空間が拡張される。
- **武器**: すべて文房具（消しゴム・チョーク・コンパス・三角定規・出席簿）。
  流血表現なし。被弾すると「制服が汚れる」「HPが減ると涙目になる」程度の表現。
- **敗北表現**: 気絶して机に突っ伏す。死なない。
- **BGM**: 授業のチャイム → 戦闘時はチャイムのフレーズをEDMにリミックス。
