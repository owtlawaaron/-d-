# 大航海の因果マップ（暗記用語問題）

1ファイルで動く静的ページ（`index.html`）。ビルド不要・サーバ不要。

- 用語23語を「説明→4択」から「書いて思い出す」へ段階的に出題し、間をあけて復習（翌日・3日後・1週間後）
- 出来事ごとの「連想の糸」：拡大した地図と自問自答（例：東ヨーロッパって？→ポーランド・ロシア→王国だが貴族が強い→農民を土地に縛れた→農場領主制）
- 因果の矢印・なぜ？・因果？相関？・地図・鎖をつなぐ（並べ替え）
- 記録は閲覧者のブラウザ（localStorage）にだけ残る

GitHub Pages で公開する場合: Settings → Pages → Source を「Deploy from a branch」、
